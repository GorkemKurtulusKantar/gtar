# 🎸 Gitar Skalası Görselleştirici

Modern ve kullanıcı dostu bir gitar skalası görselleştirme web uygulaması. Fretboard üzerinde skalaları interaktif olarak görselleştirin.

## Özellikler

- 🎯 **4 Farklı Skala**: Major, Minor, Pentatonic Major, Pentatonic Minor
- 🎹 **12 Kök Nota**: Tüm notalar (C, C#, D, D#, E, F, F#, G, G#, A, A#, B)
- 🎨 **Modern Tasarım**: Güzel ve kullanıcı dostu arayüz
- 📱 **Responsive**: Mobil ve masaüstü uyumlu
- 🎪 **İnteraktif Fretboard**: 15 perde görselleştirmesi

## Kurulum

```bash
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev

# Production build
npm run build
```

## Kullanım

1. Kök notayı seçin (C, D, E, vb.)
2. Skala tipini seçin (Major, Minor, Pentatonic Major/Minor)
3. Fretboard üzerinde skala notalarını görselleştirin
   - **Sarı**: Skala notaları
   - **Kırmızı**: Kök nota (R ile işaretli)

## Teknolojiler

- React 18
- Vite
- CSS3 (Modern gradients ve animations)
